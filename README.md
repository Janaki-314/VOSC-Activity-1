# Tic-Tac-Toe Game

This project is a simple and fully functional Tic-Tac-Toe game created for VOSC Activity-1.

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns clicking an empty box.
3. The player who gets three symbols in a row wins.
4. If all boxes are filled without a winner, the game is a draw.
5. Click the "Restart Game" button to start a new game.

## How to Run

Open the `index.html` file in a web browser.

## Project Files

- `index.html` - Structure of the game
- `style.css` - Styling and design
- `script.js` - Game logic
- `README.md` - Project information
